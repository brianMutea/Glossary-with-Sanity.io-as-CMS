# Tech Glossary Blog

Modern tech blog with Sanity CMS and Next.js. Features real-time content updates, code syntax highlighting, and responsive design.

## Quick Start

```bash
pnpm install
pnpm dev
```

- **Studio**: http://localhost:3333 (Content management)
- **Website**: http://localhost:3000 (Public blog)

## Setup Content

1. Open Studio → Create author profile
2. Add categories with colors
3. Write your first blog post
4. Content appears instantly on website

## Key Features

- **Real-time updates** - Content syncs instantly between Studio and website
- **Rich content** - Code blocks, images, videos, series support
- **Responsive design** - Works on all devices
- **SEO optimized** - Meta tags, structured data
- **Performance** - Static generation + live updates

## Content Types

- **Blog Posts** - Rich text with code, images, videos
- **Authors** - Profiles with social links and bios  
- **Categories** - Color-coded organization
- **Series** - Multi-part tutorial sequences

## Tech Stack

- **CMS**: Sanity.io v4 with Live Content API
- **Frontend**: Next.js 15+ App Router
- **Styling**: Tailwind CSS v4
- **Monorepo**: Turborepo + pnpm
